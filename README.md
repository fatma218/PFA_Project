## 📖 Description

**VRMed** est une application de réalité virtuelle développée pour **Meta Quest**, destinée à la formation des étudiants en médecine sur les procédures préopératoires chirurgicales.

### 🧴 Module implémenté : Lavage Chirurgical des Mains

Simulation guidée et interactive du protocole de lavage chirurgical, incluant :

- 🔊 **Guidage vocal** — instructions audio déclenchées automatiquement
- 🚶 **Téléportation** — déplacement vers le lavabo via zone interactive
- ✋ **Hand Tracking** — interaction naturelle sans contrôleur

- 💡 **Feedback visuel** — indicateurs pour guider l'utilisateur étape par étape
